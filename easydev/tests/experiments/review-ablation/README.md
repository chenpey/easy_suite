# 独立审查四臂消融协议

本目录只保存协议，不包含实验结果。仓库若保留历史 pilot，其材料仅用于说明设计
来源；历史 pilot 不能证明当前版本、独立审查、异构模型或弱开发加强审查的收益。

## 四臂

| 臂 | 开发 | 独立审查 | 回答的问题 |
| --- | --- | --- | --- |
| A | 基准模型 | 无 | 仅实施与自查的基线 |
| B | 基准模型 | 同模型、跨实例 | 独立审查本身是否有净收益 |
| C | 基准模型 | 同强度、不同模型家族 | 异构信息是否带来额外收益 |
| D | 较便宜/较弱模型 | 较强模型 | 成本路由是否值得 |

B 与 C 只改变审查模型的异构性；C 与 D 只改变开发/审查能力组合。不要把
“有没有审查”“是否异构”“开发者强弱”混在一条比较里。

## 任务与预算

- 任务同时覆盖局部低风险、公共契约、多调用方、高风险鉴权/数据、隐蔽 Bug 和
  长任务；不能只用 5 道 SWE-bench Lite。
- 每个任务冻结代码快照、原始请求、模型与推理深度、工具权限、网络、时间、
  最大步数和正式审查轮数。
- 每个任务使用执行者不可见的独立验收；同一任务的多臂结果按任务配对。
- 先做小样本功效模拟，再冻结任务清单和重复次数。看结果后增删任务必须另立实验。

## 记录

- 质量：隐藏验收、回归、确认缺陷的严重度与准确率、审查漏检与误报。
- 成本：主代理和全部子代理的实际 token/费用，两者分开；缺失写未知。
- 效率：墙钟时间、正式审查轮数、返工和阻塞。
- 人工负担：必要介入、人工复核时间、验收后重开。

## 采用门槛

只有在高风险任务的隐藏验收不下降，reviewer 对固定负向伪修复有可接受召回与
误报，且总成本、缓存后有效成本或耗时至少一项明确改善时，才考虑默认异构审查或
`full-local` 候选。任何单次低价、模型自述或未配对的总体均值都不能满足门槛。
当前版本不把 `full-local`/`full-staged` 放入正式运行路径。
