# 更新日志

完整历史记录。最近一次更新见 [README](README.md)。

## 0.4.5 更新说明（2026-10-19）

- 修复新 Mac 打开导出迁移脚本时被 Gatekeeper 下载隔离拦截的问题：迁移 ZIP 现在同时包含 `EasyMac-Migration.command` 和 `EasyMac-First-Run.txt`，可右键选择“打开”，或按说明从终端首次运行。
- 迁移脚本首次运行只移除自身的 `com.apple.quarantine`；删除失败时给出明确提示但继续迁移，不会关闭 Gatekeeper、修改系统安全设置或请求管理员权限。
- 导出界面和中英文说明同步首次运行恢复路径；完成首次运行后，以后可直接双击迁移脚本。
- 图标构建在 `sips` 无法渲染 SVG 时回退到系统 Quick Look，并在最终失败时保留两项工具诊断，避免新版 macOS 阻断发布包构建。
- 补充真实 ZIP 与隔离边界回归：验证 CRC、解压权限、仅清理命令自身隔离标记，以及不可写文件的非阻断提示。
- 兼容性：迁移清单和安装脚本契约保持兼容；仅新增首次运行说明文件，不会清理其他文件。新 Mac 无需安装 EasyMac；旧 Mac 需使用 0.4.5 或更新版本重新导出，才能获得首次运行说明。

## 0.4.4 更新说明（2026-09-25）

- 启动脚本 `app-launch.zsh` 改用独立临时目录，避免并发多实例启动时目录覆盖与冲突。
- 预览脚本 `scan-preview.zsh` 增加已存在目录校验，避免覆盖已有输出目录。

## 0.4.3 更新说明（2026-09-22）

- 重构国际化体系为独立字典（`i18n.js`），支持 `t(key, ...args)` 参数插值。
- HTML 采用 `data-i18n*` 标记静态文案，JS 动态文案统一使用 `t(...)` 获取，移除 `MutationObserver`。
- 新增 `scripts/check-i18n.mjs` 自动化 Key 对齐检查，确保中英文完全对称。

## 0.4.2 更新说明（2026-09-22）
