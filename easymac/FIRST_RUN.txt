EasyMac 首次使用

由于 EasyMac 没有 Apple Developer ID 公证，请先通过终端授权。

1. 打开 macOS 自带的“终端”。
2. 复制下面整行命令，粘贴到终端并按回车：

   /bin/zsh -c 'f=$(/usr/bin/find "$HOME/Downloads" -maxdepth 8 -type f -path "*/EasyMac.app/Contents/Resources/first-open.zsh" -print 2>/dev/null | /usr/bin/head -n 1); [[ -n "$f" ]] || { echo "未在下载目录找到 EasyMac"; exit 1; }; /bin/zsh "$f"'

命令会在下载目录中自动定位 EasyMac.app 及其内置授权脚本。

脚本会先验证 EasyMac.app 的签名完整性和固定应用标识，只在验证
通过后移除该应用自身的下载隔离标记，然后启动应用。

完成后会关闭当前终端标签页。以后可以直接双击 EasyMac.app。

此操作仅修改当前用户下载的 EasyMac.app，不需要也不应要求管理员密码。
