## 1.5.0 更新说明（2026-10-25）

- 编辑器内即时渲染：顶部显示模式改为「源码 / 即时渲染 / 阅读」三态，默认即时渲染，Markdown 源码仍是编辑、草稿、同步、版本、导入导出与服务端的唯一内容格式。
- 光标所在块显示源码，其余块渲染标题 1–6、粗体/斜体/删除线/行内代码/链接/行内公式、无序与有序及嵌套列表、待办、引用、围栏代码与高亮、分隔线、私有图片（点击放大）、块级公式、表格与独立 `<details>` 折叠块；点击表格、代码、公式或折叠块会整块回到源码。
- 即时渲染只重建自有 DOM：编辑区不解释原始 HTML、不加载外链图片、危险协议链接保持文字；私有图片仍在线优先、失败后才用离线缓存，公式与代码高亮沿用既有 KaTeX / highlight.js 路径与主题变量。
- 待办可直接在即时渲染中勾选，只改复选框对应的那一个任务标记且一次撤销即可回退；切换源码/即时渲染/阅读保留选区、撤销记录、插入标记与未保存草稿，并按源块恢复滚动位置；显示模式偏好按账号保存在浏览器。
- 渲染或资源失败时自动切回源码模式继续编辑保存，正文额度、服务端校验、离线草稿、分享、PDF、TOC、搜索高亮与独立阅读窗口行为不变；无需数据库迁移或内容迁移。
- 即时渲染的已知限制（不阻断使用，按现状记录）：常见块级 HTML 容器的内容按源码显示，容器识别基于有限标签集合与逐行扫描，未识别容器或注释/引号内的伪闭合标签可能被当作文本扫描；拖动选区期间收到远端同步会取消本次手势并按文档变更重新映射选区（不会写错数据）；两个源码完全相同的 details 块在增删或重建后可能复用开合状态；块级公式只剥离公式所在块自身的引用/列表前缀，公式正文里以列表形状开头的行（如 `- x`）按 TeX 内容保留；性能上，最终构建以约 240 KiB（245,692 B）的指定富文本样例实测，单键与连击均未降级，但 12 ms/帧的首轮目标未达标（保留真实数字）；该样例不代表所有 256 KiB 笔记，早前轮次的 256 KiB 采样与本次最终构建不同，输入路径仍保证不丢字与可安全降级。
- 外部内容同步的已知边界（单列，不阻断使用）：单次差异超过 200 行或 200 段时回退为单段差异，该替换段内部的光标与插入标记位置不再完整保留；正文不丢字，编辑与保存不受影响。

## 1.4.0 更新说明（2026-10-19）

- 新增笔记目录：正文中单独成段（前后空行）写 `[TOC]`，预览、只读分享、独立阅读窗口与 PDF 导出都会生成可点击目录，按标题层级嵌套编号，点击滚动到对应标题。引用块内的标题不计入，空标题自动跳过，代码块或行内出现的 `[TOC]` 保持字面文本，没有标题时显示“没有标题”。

- 新增图表另存为图片：预览与分享页中每张图表可导出 SVG 或 PNG。SVG 为矢量、体积更小，PNG 便于粘贴到不支持 SVG 的软件。导出沿用当前主题的颜色与字体并内联背景色，深色主题导出的图片不会变成白底丢失线条。
- 导出文件名由笔记标题与图表序号生成，并清理非法字符；导出内容不包含外部链接与外部图片。
- 补充浏览器回归：目录结构（含跳级标题的连续编号）、空目录、搜索时不丢目录、分享页与独立阅读窗口中的目录滚动、导出 PDF 的文本包含目录条目，以及图表另存 SVG / PNG。
- 兼容性：本次仅涉及前端渲染、交互与文档，服务端 API、数据格式、备份格式与数据库结构均不变，无需新增迁移。

## 1.3.12 更新说明（2026-10-18）

- 修复离线笔记库在断网后把列表替换为“笔记列表加载失败”的问题：后台同步不可达时继续显示本机镜像中的笔记，离线标记与后台同步提示仍然保留；此前断网浏览会让镜像列表变空，只能先重试才能恢复。
- 图表渲染引擎由 Mermaid 更换为 Pele：图表脚本由多个懒加载子分块（其中布局引擎单个约 1.5 MB）变为一个约 685 kB（gzip 约 255 kB）的分块，离线预缓存与首次预览的下载量相应下降。
- 图表主题改用 CSS 变量，深浅外观切换即时生效，不再重新渲染图表；切换主题时最多 20 个图表不再被同步重绘。
- 收紧图表输出过滤：新的渲染结果不再包含 `<style>` 元素，因此移除 sanitize 的 `<style>` 放行项，仅保留无障碍语义所需的 `role` 属性；图表中的链接与外部图片仍全部禁用，图表文本仍按转义输出。
- 图表注入防护、单篇最多 20 个图表、每个源码最多 50,000 字符等限制保持不变；补充“损坏图表显示内联错误”与“超过 20 个图表时其余显示错误”的浏览器回归。
- 兼容性：Pele 对齐 Mermaid 12.1 语法，仓库内全部 25 个示例图表块渲染通过；个别旧写法（例如在 `classDef` 或 `linkStyle` 中使用 `url(...)`）会解析失败并在原位置显示错误提示，不影响笔记其余内容。可导入 [`examples/mermaid-all-types-demo.md`](examples/mermaid-all-types-demo.md) 验收 20 种常见图型。
- 本次仅涉及前端渲染与文档，无需新增数据库迁移；服务端 API、数据格式与备份格式均不变。
